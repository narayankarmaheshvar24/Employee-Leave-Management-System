# Employee Leave Management System

A web-based Employee Leave Management System developed using Java, Spring Boot, MySQL, HTML, CSS and JavaScript.

## Technologies Used
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript

## Features

### Admin
- Admin Login
- Add and Manage Employees
- Create Employee Login Accounts
- View All Leave Requests
- Approve or Reject Leave Requests

### Employee
- Employee Login
- View Employee Profile
- Apply for Leave
- View Leave Requests
- Check Leave Balance

## Security
- Role-based access control
- Password encryption using BCrypt
- Employee-specific leave request access

## Database
MySQL
